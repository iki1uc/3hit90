# ID · Resolver-Dokumentation
CLOSED · NO-CLONE · BUSINESS

ID ist der dritte Hauptbefehl des Resolver-Systems.
Er verarbeitet Identität, Vektoren und Kontext.

---

## 1. Zweck
ID erzeugt eine Identitätsanalyse:

- Vektor wird geladen
- Magnitude wird berechnet
- Richtung wird normalisiert
- QI/IQQ werden getrimmt
- COACH aktualisiert Persönlichkeit

ID ist der "Identitätsbefehl" der Engine.

---

## 2. Auslöser
ID wird ausgelöst durch:

- Tastatur: Taste **3**
- Matrix-Klicks mit Vektor-Pfaden
- Auto-Modus

---

## 3. Ablauf
1. Vektor wird geladen  
2. Magnitude wird berechnet  
3. Richtung wird normalisiert  
4. QI/IQQ werden gesetzt  
5. COACH aktualisiert Persönlichkeit  
6. Live-Log zeigt den Schritt

---

## 4. Verbindung zu Modulen
- ID_2our(vec) → Vektor-Operator  
- RAW → Vektor-Daten  
- SYN-Engine → Visualisierung  
- COACH → Persönlichkeit  
- Pipeline → Kontextfluss
