# suite.see · System-Monitor Dokumentation
CLOSED · NO-CLONE · BUSINESS

suite.see ist der zentrale Monitor deiner Engine.
Er zeigt alle Live-Daten, Impulse, Schritte und Systemzustände in Echtzeit.

---

## 1. Zweck
suite.see dient als Beobachtungsfenster für:

- Pipeline-Schritte
- Resolver-Aktionen
- Sense-Impulse
- TMP-Pfade
- SYN-Engine-Status
- Auto-Modus-Zyklen

Damit ist suite.see der "Live-Überblick" der gesamten Engine.

---

## 2. Hauptfunktionen

### Live-Stream
Zeigt jeden Schritt sofort:
- Matrix-Klicks
- Sense-Analysen
- Resolver-Ausführungen
- AIR6D-Bewegungen
- Pipeline-Reaktionen

### Status-Layer
Zeigt:
- aktiven Sense-Zustand
- aktiven Resolver-Befehl
- aktiven TMP-Pfad
- aktiven COACH-Ordner

### Engine-Flow
Zeigt die Reihenfolge:
BOOT → Matrix → Sense → SYN → Resolver → Auto → Log

---

## 3. Verbindung zu Modulen

| Modul | Einfluss |
|-------|----------|
| **[pipeline.js](ca://s?q=Dokumentiere_pipeline_js)** | liefert Schritte |
| **[syn.core.js](ca://s?q=Dokumentiere_syn_core_js)** | liefert Energiefluss |
| **[AIR6D_MOVE.js](ca://s?q=Dokumentiere_AIR6D_MOVE_js)** | liefert Bewegungsimpulse |
| **[RAW](ca://s?q=Erklaere_RAW_Module)** | liefert TMP-Daten |
| **[7SENSE](ca://s?q=Erklaere_7SENSE)** | liefert Zustände |
| **[Resolver](ca://s?q=Erklaere_RESOLVER)** | liefert Aktionen |

suite.see ist vollständig mit allen Engine-Modulen verknüpft.

---

## 4. Bedienung
suite.see hat keine Buttons.
Es reagiert automatisch auf:

- BOOT
- Matrix
- Sense
- Resolver
- Auto-Modus

Es ist ein reines Anzeige-Modul.
