# HDFRESPO · Resolver-Dokumentation
CLOSED · NO-CLONE · BUSINESS

HDFRESPO ist der zweite Hauptbefehl des Resolver-Systems.
Er verarbeitet Reaktionen, Antworten und System-Impulse.

---

## 1. Zweck
HDFRESPO erzeugt eine Reaktion auf den aktuellen Systemzustand:

- Sense-Zustände werden ausgewertet
- Kernel liefert Cause + Allowed
- Pipeline reagiert auf TMP-Pfad
- COACH aktualisiert Wohnen + Arbeit

HDFRESPO ist der "Reaktionsbefehl" der Engine.

---

## 2. Auslöser
HDFRESPO wird ausgelöst durch:

- Tastatur: Taste **2**
- Sense-Klicks (ghost, help, error, miss, fit, fin, rdy, bioldung)
- Auto-Modus

---

## 3. Ablauf
1. Sense-Zustand wird gelesen  
2. WRAIGHT-Kernel analysiert Cause  
3. Allowed wird geprüft  
4. Pipeline erzeugt Reaktion  
5. COACH aktualisiert Wohnen/Arbeit  
6. Live-Log zeigt den Schritt

---

## 4. Verbindung zu Modulen
- 7SENSE → Zustände  
- WRAIGHT-Kernel → Analyse  
- RAW → TMP-Daten  
- Pipeline → Reaktion  
- COACH → Wohnen/Arbeit
