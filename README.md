Final Business-Version · Single-Page Engine · SYN-Kernel · Resolver · 81-Matrix

Dieses Repository enthält die vollständige RAW‑Edition der HDF‑SYN‑Engine.

---

## 1) Systemübersicht

Die Engine besteht aus mehreren Kernmodulen:

- **ROOT** – Hauptverzeichnis der Engine
- **RAW** – Rohdaten, unverarbeitete Kernmodule
- **r.md** – Systemnotizen, RAW‑Dokumentation
- **syn** – SYN‑Achsen, Sense‑Kernel, Triangle‑Flow
- **AIR6D_MOVE.js** – 6D‑Bewegungsmodul
- **pipeline.js** – HDF‑Pipeline‑Controller
- **syn.core.js** – SYN‑Kernel‑Core
- **index.html** – Hauptseite, Engine‑Startpunkt
- **syn1.html** – SYN‑Testseite
